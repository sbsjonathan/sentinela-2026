Bíblia de Estudo em português incluída para leitura local/offline.
Banco SQLite original, compactado com gzip e dividido em partes de até 8 MiB.
Concatene as partes na ordem do manifesto e descompacte com gunzip.
As imagens JPG permanecem byte a byte idênticas; SVG usa gzip sem alterar o conteúdo.
A chave file do manifesto corresponde ao nome usado no banco; path aponta para o asset.
Vídeos e áudios externos não estão contidos no pacote original.
